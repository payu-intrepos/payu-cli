PayU CLI

Manage payments, transactions, refunds, and settlements from your terminal.

Quick Install

Run this in your terminal (macOS or Linux):

curl -fsSL https://payu-intrepos.github.io/payu-cli/install.sh | bash

Manual Download

macOS (Apple Silicon) payu_mac-os_arm64.tar.gz
macOS (Intel) payu_mac-os_x86_64.tar.gz
Linux (x86_64) payu_linux_x86_64.tar.gz
Linux (ARM64) payu_linux_arm64.tar.gz

Download from the latest release, then:

tar -xzf payu_*.tar.gz && sudo mv payu /usr/local/bin/

Get Started

# Configure your credentials
payu config set

# Verify
payu version

Commands

payu pay create-link # Create a payment link
payu pay list # List payment links
payu txn list # List transactions
payu txn get <id> # Transaction details
payu refund search # Search refunds
payu settlement get # Settlement details
payu report create # Generate CSV report

Run payu --help or any command without arguments to see all options.
